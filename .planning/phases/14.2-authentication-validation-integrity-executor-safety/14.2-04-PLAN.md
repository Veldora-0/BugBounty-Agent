# Plan 14.2-04: Comprehensive Safety, Integration & Lab Verification Suite

## Objective
Build a comprehensive regression and verification test suite for Phase 14.2 covering request sequences, state transitions, scope enforcement, TLS verification, redirect handling, anti-SSRF defenses (including IPv4-mapped IPv6), DNS rebinding safeguards, credential redaction, state persistence, resume, and finding lifecycles. Preserve and verify all 21 offline lab scenarios; add local HTTP fixture tests with negative controls for every operational family; assert zero DNS and socket activity in offline modes; verify that `bb-doctor` Category 23 reports healthy; synchronize global OpenCode deployments (`bb-deploy`); update all documentation; and conclude implementation in a single consolidated commit: `fix: correct authentication validation integrity and executor safety`.

## Context
Phase 14.2 establishes strict validation integrity and executor safety. Tests must prove that:
1. Real execution paths never use hardcoded synthetic response strings to validate findings.
2. Missing researcher identities or prerequisites result in non-validated states, not fabricated findings.
3. Negative controls (non-vulnerable endpoints) deterministically reject hypotheses.
4. Offline modes (`--dry-run`, `--passive-only`, `--lab`) strictly make zero socket connections and zero DNS resolutions.
5. SSRF defenses block IPv4-mapped IPv6, loopback, private ranges, and cloud metadata.
6. Scope resolution fails closed without unsafe working directory fallbacks.
7. All 21 lab scenarios pass 100%, full regression suite passes 100%, and Category 23 in `bb-doctor` reports healthy.
